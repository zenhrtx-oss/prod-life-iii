## Added in Milestone 6 "Piano roll" (2026-10-22 night)
- Beat format v3 (Modules/DAWConfig): 128 characters = the 80 drum cells plus a keys lane of 3 voice rows × 16 steps. A keys cell is "0", a note letter ("m" = the root, "a".. "y" = -12..+12 semitones) or "-" holding the note before it; up to 3 notes sound together. v1/v2 beats upgrade on load and on the server (DAW.Validate); CellsDiffer / BriefCheck.Changed count notes as pads, so flips, cyphers and "make it yours" cover melodies.
- The KEYS view (Modules/PianoRoll, KEYS/DRUMS button, K or gamepad Y): rows are pitches (highest at the top, note names relative to the root), columns the 16 steps. Tap to place a note (LEN 1/2/4 steps), tap a note to remove it, press and drag along the row to stretch it; VOICE picks the instrument; SCALE locks the rows to MINOR PENT (default), MAJOR PENT, MINOR, MAJOR or ALL NOTES; phones get 44 px rows in a scrolling list. CLEAR empties only the lane you are looking at (UNDO brings the whole beat back).
- Voices (DAWConfig.Voices, Samples.Voices, DAWEngine:PlayNote): one licensed single note each, repitched by PlaybackSpeed and held for the note's length then faded. MUSIC BOX is free; PLUCK ($600, rack tier 2) and CHIME ($1,100, tier 4) (prices ×10 since the 2026-10-23 money rescale) are gear of kind "voice". Tuning was measured in Studio with AudioAnalyzer (2048 linear bins, 11.72 Hz each): the 808's body sits at 38.1 Hz (D#1 - 36 cents), so every voice's Tune puts its root on that pitch class. The user should still listen.
- The voice travels with the beat: slots store it, DAW_Save / DAW_Broadcast / Cypher_Submit validate it (an unowned voice is refused), NowPlaying.Voice tells every listener which sample to play, SAMPLE IT keeps the melody and the voice when you own it.
- Rules that keep it fair: one voice per pitch at a time (KeysValid refuses a lane that stacks the same note; placing or stretching stops before the next note of that pitch); a held note is one pad, so ties never count towards "make it yours", flips or save XP (BriefCheck.Diff); a vertical swipe on a phone scrolls the rows without placing or removing a note; a note outside the scale lock keeps its row on screen until you remove it.
- Session requests can ask for keys (BriefCheck kinds melody / melnotes / chord, no gear needed): j2 and r2 now have keys bonuses, dailies have a 9th template and the Weekly Single a 7th. Templates added later are gated by date (DailyRequests.TemplateCount / WeeklyCount) because ids are seeded by the date: a day or week already generated keeps its asks.
- Tests: t30_check (format helpers, validation, grader, rack, monitors, the KEYS view driven through its gesture API), t30 / t30b / t30c play tests (window, playback timing and note gates, per-lane CLEAR, saves, refusals, phone layout, voice gear on the preview and the monitors).

## Added in Milestone 7 "FL-style piano roll" (2026-10-23 night)
- The KEYS view now reads like FL Studio's piano roll (Modules/PianoRoll): a piano keyboard down the left (white/black key shapes, click one to hear it), rows shaded by the scale lock (in-scale lighter, roots tinted, off-scale dark in ALL NOTES), beat lines, a playhead line, green note bars with their name and a grab handle on the last cell, and the 808's notes drawn as faint ghost notes on their rows.
- Editing like FL: tap an empty cell to place a note; drag a note's body to move it (a mouse moves pitch too, a finger moves in time only so swipes keep scrolling); drag its last cell (the right half of a one-step note) to stretch; tap a note or right-click it to remove. A move never changes a note's length and never lands on another note of the same pitch.
- Velocity lane under the rows: one bar per note start, tap or drag across it to set accents. An accent is an UPPERCASE note letter in the keys lane (format v3 stays 128 characters; the server accepts both cases and still refuses stacked pitches), plays Keys.Accent (1.35x) louder, and never counts as a changed pad (BriefCheck.Diff ignores ties and letter case, so painting accents cannot make a copied beat "yours").
- CHORD stamp: with CHORD on, a tap places a 1-3-5 triad built from the scale's degrees (pentatonic scales borrow their parent minor/major scale; a major triad on an off-scale row), clipped to the lane and to free voices.
- Tests: t30_check covers accent letters, MoveNote/SetAccent, ChordNotes, the move/stretch/scroll gesture modes, the velocity lane, the chord stamp and ghost notes; t30 play checks the lane on phones, that an accent plays louder and that CHORD places three notes.

## Save safety (2026-11-04)
Plan `plans/2026-11-03-save-safety.md`. Fixes two rare save-loss cases older than Wave 2 (the Wave 2 save lens, findings 3 and 5). No schema change (still v5).
- **Generation:** every write that marks a profile dirty goes through `touch(p)` (Load, MarkDirty, applyXP, applyCred, SpendCred, TakeCred), which also bumps `gen[uid]`. Save clears `dirty` only when the generation hasn't moved and the cached profile is still the one it saved, so a change made while the store was busy goes out with the next autosave. A release that finds the profile dirty again saves once more.
- **One moment per save:** `clean()` deep-copies the profile inside the save's pcall, so the stored document never mixes moments.
- **Writer token:** each load makes a GUID, stored as `writer` beside `lock` at the lock claim and on every save, release included (release clears only the lock). The token stays out of the profile and `ClientProfile`. The save callback refuses (`_lockLost`) on a foreign lock, a stored writer that isn't ours, or a stored `v` newer than ours, so a stale server can't overwrite a newer session after a takeover. A document with no writer saves and then carries ours.
- **Real-save trial** (Studio only; a live server ignores it): `tools/real_save_on.lua` sets `ReplicatedStorage.OK.RealSaveTrial = "ProdLife_trial_v1"`, so a Play session saves to that separate DataStore, never `OKStudio_v1`. `tools/real_save_check.lua` reads the stored document (read only) and `tools/real_save_off.lua` clears the switch. `tools/guard.lua` refuses syncs and test runs while it's on. It needs Game Settings > Security > Enable Studio Access to API Services.
