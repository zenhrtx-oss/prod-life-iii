## For the content writer: never type these

The data spec fails any card or follow-up text, WaitLine or NoteLine that contains a display name from either roster as a plain lowercase substring, with tokens stripped first (`spec/walkins_data_spec.lua`, "content text never types a display name"). It also fails any fiction-filled text that contains a parody name ("fiction fill has no parody name"). Write `{name:<id>}` instead. These are the phrases the new cards are most likely to type by accident:

  - Card text names no person or organisation except the names in this file. A new proper noun gets its own anchor here, with the same checks, before it goes into a card.

## Verdict rule (written before searching)

**Queries.**
- Every name gets two WebSearch queries in standard mode: `"<NAME>" rapper OR singer OR band` and `"<NAME>" company OR brand OR app`. Role names also get `OR show` on the second query.
- The quoted phrase drops a leading A or THE only where keeping it would narrow the match. Each table row shows the exact phrase used.
- The programme name gets a third query: `"<NAME>" youth music program OR nonprofit OR charity`. Each distinctive word is also checked for a known product or act. The 10-23 file dropped STIRRUP PIXEL because of "Pixel".

**Verdicts.**
- **Invented names** (the programme): replace on any exact match to a real act, company, brand, app, programme or public figure.
- **Role names and phone labels** made of common words: replace when the exact phrase names a real act, company, brand, product, app, programme or public figure that a player could read the name as pointing to. That means a music game whose new cards arrive as phone alerts: apps, alerts, music, media and youth programmes.
- **Keep** when the results show only:
  - the phrase in its plain sense
  - a generic feature name that many companies use
  - longer or reordered names
  - works by unrelated artists (songs, films, documentaries), which are recorded as notes. This follows the 10-23 rule, where a title counted only when it was tied to one of the nine parodied artists.
- **Unsafe associations:** replace a name whose wording evokes something unsafe for the game's audience, even without an exact match.
- **User-decided names** (YOUR MOM: design §4.3, "user: 'your mom'"): checked and reported. A hit is flagged for the user, not replaced.
- **Replacements** go through the same queries and are recorded under the same anchor.

**Local checks.**
- A scratch Luau script loaded `Data/WalkIns` at base e15734b and collected its 4,042 strings, the same way the spec's safety scan does.
- For each name it checked that:
  - the name is not a substring of any existing string (tokens stripped, lowercase)
  - the name contains no REAL or TITLES entry and no BLOCK word
  - the name does not match a t50 pattern or CRED
  - fiction ≠ parody for every name, no fiction name contains a parody name, and names are unique within each roster
- All 22 final names and the programme name pass.
- **Control.** "big room" and "beat" are found in existing text, and "INCREDIBLE", "BOOK STUDIO TIME" and "A&M" trip the t50/CRED patterns.
- These checks cover only today's text. The "never type these" list above covers the new text.
