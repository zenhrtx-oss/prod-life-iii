## Review Focus

1. **The target leaves, dies, respawns or walks into Studio Two before arrival or with the card open:** the visitor walks out and is destroyed; the in-flight record clears; no stat change; a visit that already arrived stays counted; the persisted pick is reused by the next spawn (no rerolling); no orphan parts under `OK_Visitors`. Tests: Task 6 `t43c_play_server` "respawn before arrival keeps the pick", "respawn with card open".
2. **Choose spam:** a second `WalkIn_Choose` with the same token, a token before arrival, an expired or other player's token, index 5 / −1 / "1" / 1.5: refused `stale`/`invalid`, effects applied exactly once. Test: Task 6 `t43_play_server`.
3. **UTC day rollover with a card open or a follow-up queued:** the open card resolves normally; `today` resets on the next schedule check; the queue survives the day change and a save/load. Tests: Task 2 `walkin_rules_spec` "rollover keeps queue"; Task 3 `t41_check` "walkins survive migrate"; Task 6 `t43b` "rollover".
4. **$0 meets a money loss, or a fixed-cost choice you can't afford:** losses take what you have (Money never < 0) and the chip shows what was taken; an unaffordable choice is refused before any roll and greyed on the client. Content rule: money risk that should bite is a `cost`, not a negative outcome on a free choice. Tests: Task 2 spec "loss clamps at zero", "afford refused"; Task 6 `t43` "unaffordable", "loss at $0".
5. **A cypher round, an unfinished tour, the beat maker or the listen-back cutaway when he arrives:** no scheduling before the tour is done/skipped or while the cypher isn't idle; on the client the card defers to the Waiting chip while the beat maker is open, the cutaway runs, or the cypher phase isn't idle, and opens when all clear. Tests: Task 6 `t43b` "tour blocks", "cypher blocks" (each next to a positive control); Task 7 `t47d_play_client` "defers while beat maker open" (cypher idle), `t47f_play_client` "defers during cypher" (beat maker closed).

## Shared shapes (every task uses these names)

```text
Outcome  = { key, headline, text, line: string, tone: "win"|"loss"|"neutral",
             -- no tag field: the overhead tag is always WalkInRules.TagFor(applied, Format, tone)
             money, aura, followers, placements, hits, sponsors: number?,
             sponsor: string?,                     -- sponsor id to sign, or "drop"
             plant: { id: string, at: {number, number}? }?,  -- follow-up id; at defaults to input followupAt
             note: string?, cooldown: number? }
Choice   = { text: string, cost: number?, sure: boolean?, odds: number?,      -- odds default 50
             good: Outcome, bad: Outcome?, rare: Outcome?, rareOdds: number? }
Card     = { id, visitor, tag, line: string, choices: {Choice} (2..4),
             weight: number?, minCount: number?,
             sponsor: string?,                     -- the brand a rep card is about (fills {sponsor})
             when: "unsponsored"|"sponsored"? }    -- eligibility by current deal; nil = always
Followup = { id, visitor, tag, line: string,
             resolve: { odds: number, good: Outcome, bad: Outcome },   -- rolled on arrival ("news")
             choices: {Choice}? }                                       -- nil = news only; else 2..4
Visitor  = { id: string, kind: "artist"|"rep"|"blogger"|"fan"|"rival"|"manager",
             names: { parody: string, fiction: string }, style: string,
             color: {number, number, number},      -- 0..255 RGB
             sig: "cowboy_hat"|"bat_ears"|"spiky_hair"|"blob_hat"|"helmet"|"llama_ears"|"sparkle_cape"|"owl_hood"|"green_roots"|"suit"|"cap"|"headphones"|"none" }
Sponsor  = { id: string, names: { parody: string, fiction: string }, kind: string, floor: number }  -- floor = min Aura to keep the deal
Career   = { money, aura, followers, placements, hits, sponsors: number, sponsor: string?, showSponsor: boolean, gates: {[id]: true} }
Deck     = { cards: {Card}, followups: {[id]: Followup}, sponsors: {[id]: floor} }   -- Data/WalkIns exports it as .Deck
Queue entry = { id: string, at: number, ctx: { sponsor: string? }? }
prof.career  = { aura=0, followers=0, placements=0, hits=0, sponsors=0, sponsor=nil, showSponsor=true, gates={}, careerLog={} }
prof.walkins = { day=0, today=0, count=0, queue={}, seen={}, last={}, next=nil }   -- next = { kind="card"|"followup", id } persisted pick
```
`{name:<visitorId>}` and `{sponsor}` in any text are filled by `WalkInRules.Fill`, which expands every `{name:…}` first and `{sponsor}` second (a rep's display name contains `{sponsor}`). Display names in the arrive payload and on the visitor's nameplate also go through `Fill`. No filled text may contain `{`.

**Money path (one contract):** a choice's `cost` is charged with `SpendCred(cost)` (refused before any roll if unaffordable); the outcome's `money` is then applied on its own: `AddCred(p, money, "WalkIn")` if > 0, `TakeCred(p, -money)` if < 0 (clamps at $0). Result chips show `-$cost` (when cost > 0) and the money actually applied, so the chips sum to the balance change. The sim (`WalkInRules.ApplyMoney`) does exactly the same.

Remotes (created by `build/17_career_remotes.lua`, Task 3): RemoteFunctions `Career_Get`, `Career_Unlock`, `WalkIn_Choose`; RemoteEvent `WalkIn`.

`WalkIn` server → client:
- `("arrive", { token, card = { id, visitor = { name, style, color }, tag, line, choices = { { text, cost } }, news = ResultPayload? }, today, max })` — `today` = `prof.walkins.today` after the arrival increment.
- `("result", ResultPayload)`, `ResultPayload = { token, key, headline, text, tone, chips = { { label, kind } }, note }`, `kind` ∈ money|aura|followers|placements|hits|sponsors; chips built from applied amounts.
- `("leave", { token })`

`WalkIn_Choose:InvokeServer(token, index)` → `{ ok = true, result = ResultPayload }` or `{ ok = false, reason = "stale"|"invalid"|"afford" }`; `index = 0` is WALK AWAY.

Studio hooks (Studio + running only, i.e. `RunService:IsStudio() and RunService:IsRunning()`), all under `ServerScriptService.OK`, invoked as `hook:Invoke(cmd, userId, ...)`:
- `_StudioCareerHook` (Task 3): `Set(userId, stats)` (keys money/aura/followers/placements/hits/sponsors/sponsor/showSponsor; money sets `prof.cred`; `sponsor = false` clears the deal; publishes attributes), `Get(userId)`, `State(userId) -> Career.State(p)`, `Equip(userId, gearId)` (calls the live `Gear.Equip`), `Take(userId, stat, n)` (calls `Career.Take`), `Reset(userId)`, `Unlock(userId, gateId)`, `FeedDelivered(userId, stars, first)`, `Publish(userId)`.
- `_StudioWalkInHook` (Task 6):
  - `Pause(_, on)` sets `RS.OK.WalkInsPaused` (the live 1 s loop skips while paused).
  - `Spawn(userId, id?)` — id = card or follow-up id; nil = the scheduler's own pick. Bypasses pause, the presence timer, tour and cypher checks, DailyMax and MaxWalking; not the hub check or the per-player in-flight block.
  - `SpawnExtra(userId, n)` — queues `n` decoy visitors (no card; they walk to the player and leave on arrival) through the real `Admit`/MaxWalking path, bypassing only the per-player in-flight block. `Waiting() -> n`, `Walking() -> n`.
  - `Poke(userId)` — one synchronous scheduler tick for that player with `remaining = 0`, **ignoring pause**; returns `true` if it spawned; if it didn't spawn, restores the previous `remaining`.
  - `SetRemaining(userId, s)`, `GetRemaining(userId)`.
  - `Reset(userId)` — clears state, the in-flight record and that player's visitors; stores defaults with `day` = current UTC day and `remaining = 1e6` (never 0).
  - `SetToday(userId, n)` — sets `today = n` **and** stamps `day` = current UTC day. `SetDay(userId, yyyymmdd)`, `AdvanceVisits(userId, n)`.
  - `Choose(userId, token, index)`, `Pending(userId) -> { token, id, arrived }?`, `Expire(userId)`.
  - `SetRng(userId, list)` — the next `rng(lo, hi)` results for that player's **Pick/Resolve/ResolveNews/Plant** draws only; FirstDelay/Gap use a separate RNG.
- `_StudioUnlocksHook` (Task 8): `Door(userId) -> toastText`, `Equip(userId, gearId)`, `Ticker() -> tvText`, `TV(userId) -> acted, toastText` (runs the real TV handler through InteractionService's Studio-only `_RunHandler`).
